# Waste Management Tycoon — Classroom Multiplayer
Requires Node.js 18+; no npm dependencies. Run `node server.js` in this folder, then open http://localhost:3000 on the teacher computer. Students on the same reachable network use http://TEACHER-IP:3000 (not localhost). On Windows use `ipconfig` to find IPv4. Allow inbound TCP 3000 if school IT permits; school Wi-Fi may isolate devices. Alternatively deploy this folder as a Node web service (start command `node server.js`, PORT supplied by host) and share its HTTPS URL. Static hosting alone will not work. No public server is provisioned by this package.
Teacher selects Host game, shares six-digit PIN, starts when teams join, advances when everyone finishes, or closes incomplete turns. Teams use one browser tab each; reload restores session while the server is running. The final ranking updates automatically every 1.5 seconds. Eligible teams ranked by score, then health and sustainability; debt disqualifies. Start $100M, $20M grant each year including year 1. Two purchases max per round. Ten science questions: first correct +5 science and $5M; ordinary retry correct +2 science; two wrong no bonus; years 3 and 4 second question is a crisis with one attempt and -10 health if wrong. Unanswered crisis on timeout also loses 10 health. All costs and scores are fictional. Score = sustainability + health + floor(cash/5) + science.
Rooms are in memory: restarting server deletes rooms. No personal student details needed. Use anonymous city names. Teacher and student session credentials stay in sessionStorage. For public long-term deployment add persistent storage, request limits and school-approved access controls. Local network use depends on IT policy.

V4: Before running each year, teams can offer waste to another city, with a positive or negative total price. Recipient must accept. Years 3 and 5 damage one existing working industrial building; $12M repair. Uncontrolled operating industrial buildings incur $2M in year 1, $4M thereafter; $10M retrofit avoids this simulated fine and reduces risk. Three questions per year, third question in years 3 and 4 is a crisis. Maximum science score 75. Costs and impacts are fictional teaching values. Start with node server.js; no external dependencies. Public deployment still required for internet access.
